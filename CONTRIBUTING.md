# CONTRIBUTING

## Branching

Nazwy branchy:

zwierze-swoje_imie

Przykład:

tygrys-ivan

## Commity

Format:

Dodano [nazwa zwierzęcia]

Przykład:

Dodano Tygrysa Syberyjskiego

## Pull Request

Każda zmiana musi być wysłana poprzez Pull Request.

## Komunikacja

Wszelkie problemy należy zgłaszać poprzez GitHub Issues.
